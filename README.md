# Property Rent Hub website

Live site: https://aqibshafiq89-bot.github.io/property-rent-hub/

This branch (`main`) holds the published website: plain HTML, CSS, images and the sitemap. GitHub Pages serves it from Settings → Pages → *Deploy from a branch* → `main` → `/ (root)`.

These files are generated, so don't edit them here. Change the source on the [`source`](../../tree/source) branch (`content/` and `site.json`), run `python3 build.py`, then copy the new `dist/` folder over these files and push. The README on the `source` branch explains each step.
